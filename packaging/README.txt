tor2vid — смотреть торрент, не дожидаясь загрузки
=================================================

Запуск
  Двойной щелчок по tor2vid.bat.
  Если Windows пишет «Windows защитила компьютер» —
  «Подробнее» → «Выполнить в любом случае».
  Если брандмауэр спросит про доступ к сети — разрешите.

Только просмотр: плеер ничего не раздаёт другим участникам торрент-сети
и не даёт скачать файл. Просмотренное удаляется само.

Откроется браузер с плеером (адрес http://localhost:3000).
Пока смотрите, окно с текстом не закрывайте. Закрыли окно — плеер остановился.

Ничего устанавливать не нужно: внутри уже есть Node.js и ffmpeg.
Скачанные куски фильмов лежат во временной папке и удаляются сами.

Настройки (по желанию — допишите в tor2vid.bat строкой set ИМЯ=значение
перед строкой с node):
  PORT=3000                 порт плеера
  OPEN_BROWSER=0            не открывать браузер
  TRANSCODE_MAX_HEIGHT=1080 предел высоты кадра при перекодировании
  TRANSCODE_PRESET=veryfast скорость x264 (ultrafast — быстрее, но крупнее поток)

Исходный код: https://github.com/vdoma88/tor2vid

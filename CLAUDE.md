# tor2vid

Онлайн-плеер для торрентов: сервер на webtorrent качает только нужный кусок
файла и отдаёт его браузеру по HTTP с Range. Node 20+, без сборки.

## Дизайн

@DESIGN.md

Взят один стиль — Linear из VoltAgent/awesome-design-md. Другие не смешивать.

## Правила

- Строгий CSP: никаких inline-стилей и скриптов, `innerHTML` не использовать.
- `uint8-util` закреплён на 2.2.6 через `overrides`: с 2.3.x webtorrent 2.8.5
  падает при добавлении любой magnet-ссылки.
- Перекодирование — `transcode.js` (ffmpeg из `ffmpeg-static`). Без ffmpeg
  сервер работает, просто играет только MP4/WebM.
- Встроенные субтитры пишутся тем же ffmpeg в `.vtt` с `-avoid_negative_ts
  disabled`; ноль у видео, звука и субтитров общий только потому, что старт
  выровнен по ключевому кадру (`seekPoint`). Не убирать одно без другого.
- Приложение для компьютера — только Windows (`packaging/`, workflow
  `release.yml`). Собирается при пуше в основную ветку, релиз
  `v<version>` из package.json; новая версия — поднять `version`.
- Каталог (`catalog.js`) — только Internet Archive, только отметка
  «общественное достояние» и год до `CATALOG_MAX_YEAR` (1950). Трекеры и
  свежие фильмы туда не добавлять: это раздача пиратских копий.
- Только просмотр: никакой отдачи (`noUpload` в server.js), никакого
  скачивания файла, ссылок «поделиться» и магнетов в адресе страницы. Все
  адреса торрента — только своему сеансу (`ownedTorrent`). Не ослаблять.
- Тексты для людей — по-русски.
